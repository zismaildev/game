# Network Puzzle Simulator 🌐

เกมจำลองการวางระบบเครือข่ายคอมพิวเตอร์ (Computer Network) และความมั่นคงปลอดภัยทางไซเบอร์ (Cybersecurity) แบบอินเทอร์แอคทีฟ ที่ออกแบบมาเพื่อใช้เป็นสื่อการเรียนการสอน ผู้เล่นจะได้เรียนรู้ตั้งแต่การลากสายเคเบิลพื้นฐาน ไปจนถึงการจัดวางสวิตช์ เราเตอร์ และไฟร์วอลล์เพื่อป้องกันการโจมตีจากแฮกเกอร์

## 🌟 ฟีเจอร์หลัก (Features)
- **โหมดเนื้อหา (Chapters 1-4):** เรียนรู้การทำงานของเครือข่ายแบบค่อยเป็นค่อยไป ตั้งแต่ระบบ LAN พื้นฐาน, Switching, Routing, และระบบรักษาความปลอดภัย (Firewall)
- **โหมดอิสระ (Sandbox):** ทดลองวางอุปกรณ์และจำลองการรับส่งข้อมูล (Packet Simulation) ได้อย่างอิสระ ไม่มีขีดจำกัด
- **ภารกิจสุ่ม (Endless Mode):** ระบบสุ่มด่านที่ไม่ซ้ำซาก ท้าทายความสามารถในการแก้ปัญหา พร้อมระบบคำนวณคะแนนตามความคุ้มค่าของการใช้อุปกรณ์
- **ระบบบัญชีนักเรียน (Student Profiles):** ระบบล็อคอินที่สมัครสมาชิกให้อัตโนมัติ พร้อมบันทึกคะแนนสะสมข้ามรอบการเล่น
- **กระดานผู้นำ (Leaderboard):** จัดอันดับคะแนนสะสมของนักเรียนทั้งหมดในระบบ
- **แดชบอร์ดคุณครู (Teacher Dashboard):** หน้าต่างพิเศษสำหรับผู้สอน เพื่อดูภาพรวมคะแนน และประเมินระดับความเข้าใจของนักเรียนแต่ละคนแบบเรียลไทม์

## 💻 สิ่งที่ต้องมี (Prerequisites)
- [Node.js](https://nodejs.org/) (สำหรับรัน Local Server)

---

## 🚀 วิธีการติดตั้งและเข้าเล่นเกม

1. เปิด Terminal (หรือ Command Prompt) ในโฟลเดอร์โปรเจกต์นี้
2. ติดตั้งไลบรารีที่จำเป็นด้วยคำสั่ง:
   ```bash
   npm install
   ```
3. รันระบบเซิร์ฟเวอร์ด้วยคำสั่ง:
   ```bash
   node server.js
   ```
   *(Terminal จะแสดงข้อความว่า `Server is running at http://localhost:3000`)*
4. เปิดเว็บเบราว์เซอร์ แล้วเข้าไปที่ URL:
   👉 **[http://localhost:3000/game.html](http://localhost:3000/game.html)**

---

## 🔑 ข้อมูลการเข้าสู่ระบบ (Login)

ระบบมีบัญชี 2 ระดับ ได้แก่:

1. **นักเรียน (Student)**
   - **Username:** พิมพ์ชื่ออะไรก็ได้ (เช่น `student1`, `somchai`) 
   - **Password:** พิมพ์รหัสผ่านอะไรก็ได้
   - *หมายเหตุ: หากชื่อนั้นยังไม่มีในระบบ (users.json) ระบบจะทำการสมัครสมาชิกให้โดยอัตโนมัติ*

2. **คุณครู (Teacher)**
   - **Username:** `teacher`
   - **Password:** `1234`
   - *หมายเหตุ: เมื่อล็อคอินด้วยไอดีนี้ จะเข้าสู่หน้า Teacher Dashboard เพื่อดูคะแนนนักเรียนทั้งหมด*

---

## 🛠️ โครงสร้างไฟล์ในโปรเจกต์
- `game.html` : โค้ดส่วนหน้าบ้าน (Frontend) ทั้งหมด รวมถึง UI, แคนวาสเกม, และลอจิกการเล่น
- `server.js` : โค้ดส่วนหลังบ้าน (Backend API) เขียนด้วย Express.js ทำหน้าที่จัดการระบบ Login และบันทึกคะแนน
- `users.json` : ไฟล์ฐานข้อมูลจำลอง (Database) สำหรับเก็บข้อมูลบัญชีผู้ใช้และคะแนนสะสม
- `package.json` : รายละเอียดของโปรเจกต์และรายการ Dependencies (`express`, `cors`)
